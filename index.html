Fonctionnalités couvertes

🔵 Installation Wazuh all-in-one
Déploiement Indexer, Manager, Dashboard et Filebeat sur un seul serveur Debian 13. Configuration SSL/TLS et certificats automatisés.
🟣 File Integrity Monitoring (FIM)
Surveillance en temps réel des fichiers et répertoires. Mode Whodata pour traçabilité complète (utilisateur, processus, PID) sur Linux (auditd) et Windows.
🟠 Suricata IDS → IPS
Détection d'intrusion réseau avec 46 334 règles Emerging Threats. Configuration AF_PACKET, optimisation GRO/LRO et intégration eve.json vers Wazuh.
⚡ Active Response — Brute Force SSH
Blocage automatique via firewall-drop après 8 tentatives en 120 s (règle 5763). Test avec Hydra + pwgen. Déblocage automatique après 3 min. MITRE ATT&CK T1110.
🟢 Intégration VirusTotal
Soumission automatique des hashs SHA256 à l'API VirusTotal lors de toute détection FIM. Suppression automatique des fichiers malveillants via Active Response.
